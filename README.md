## 玩法

- 限時 30 秒，答對 +100、答錯 −50（最低 0 分）
- 每投一球，LED 矩陣會依序播報答對數、答錯數、目前得分
- **2D 版**：點畫面上的籃框投籃
- **3D 版**：點 3D 籃框、按下方按鈕或鍵盤 `1`～`4` 投籃；可拖曳旋轉視角；每球播報時倒數暫停；答錯時正確的籃框會閃爍提示

### 📷 攝影機投籃（3D 版）

按右上角「📷 攝影機」並允許使用攝影機（需 HTTPS，GitHub Pages 網址即可）。第一次會下載姿勢辨識模型，約 10～20 秒。

1. **瞄準**：鏡頭畫面分成四欄，左→右對應 1～4 號籃框；瞄準中的籃框燈環會整圈亮起
   - 「站的位置」：左右移動身體選籃框（適合展場、站遠一點）
   - 「手的位置」：舉起的那隻手在哪一欄就投哪一框（適合空間小）
2. **投籃**：手先放到肩膀以下，再快速往上推過畫面上的黃色「投籃線」；手要放低才能投下一球
3. **開始遊戲**：舉起雙手維持 1 秒
4. **靈敏度**：偵測不到就調「高」，太容易誤投就調「低」

建議站在鏡頭前 1.5～3 公尺，讓上半身（雙肩、雙手）完整入鏡。
